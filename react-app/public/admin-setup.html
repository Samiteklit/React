THE KORA HOUSE · LOCAL SHOP

Your shop stays right here.

KORA now saves its products and photos directly on this computer. There is no online account or database setup to connect.

Start the shop

When the shop is running, go to Admin. The first time, choose a password. After that, use the password to open the product studio.

Add fragrances and photos

In the admin studio, select a fragrance to edit it or use “Add a scent” for a new one. Choose a JPG, PNG, or WebP product photo up to 5 MB, then save. The public shop updates from that saved list.

Keep a backup

The database and photos live in the data folder inside your KORA project:

data/kora.sqlite
data/uploads/

This is a local shop: its products and admin password are stored on this computer. It will not sync to another device or be available online. Copy the data folder to keep a backup.
